Jak uruchomić ten projekt?

💡
Ten projekt zawiera backend PHP i bazę danych MySQL.

Przeglądarka internetowa nie potrafi samodzielnie przetworzyć kodu PHP ani połączyć się z bazą danych bez lokalnego serwera (np. XAMPP).

1. 👁️ Szybki podgląd kodu i kwerend (bez instalacji)

Możesz od razu zobaczyć kompletny kod źródłowy PHP, strukturę tabel i kwerendy SQL bezpośrednio w panelu.

2. 📥 Pobierz gotową paczkę ZIP z instrukcją

Pobierz archiwum zawierające wszystkie pliki projektu, bazę .sql oraz plik README.md z instrukcją krok po kroku.

Instrukcja obsługi panelu i projektów

🚀 1. Jak korzystać z panelu

  • Wyszukiwarka i filtry: Wpisz rok, słowo kluczowe (np. ryby, komis, pesel) lub wybierz kwalifikację (E.14, EE.09).
  • Otwieranie projektów: Kliknij 🚀 Otwórz. Strony HTML otworzą się od razu, a dla projektów PHP otrzymasz wskazówki i podgląd kodu.
  • Podgląd kodu: Przycisk 👁️ Rozwiązanie otwiera okno z kodem źródłowym, kwerendami SQL i opisem co było robione.
  • Pobieranie ZIP: Każda paczka ZIP zawiera komplet plików oraz plik README.md wyjaśniający co zrobić po pobraniu.

🐘 2. Jak uruchomić PHP z bazą MySQL w XAMPP

  1. Pobierz i uruchom XAMPP (moduły Apache i MySQL).
  2. Wejdź na http://localhost/phpmyadmin i zaimportuj plik .sql.
  3. Skopiuj folder z zadaniem do C:\xampp\htdocs\.
  4. Otwórz stronę w przeglądarce pod adresem http://localhost/[nazwa_folderu].
