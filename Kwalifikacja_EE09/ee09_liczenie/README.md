# 📌 ee09_liczenie (EE.09 (Programowanie i administrowanie stronami oraz bazami))

> **Temat zadania:** Aplikacja Matematyczna i Działania  
> **Kwalifikacja:** EE.09 (Programowanie i administrowanie stronami oraz bazami)  
> **Technologie:** HTML5, CSS3, JavaScript

---

## 📖 Opis zadania i co zostało zrobione

Kalkulator podstawowych działań matematycznych (dodawanie, odejmowanie, mnożenie, dzielenie, potęgowanie) w JS.

### Główne elementy rozwiązania:
- Opracowanie semantycznej struktury strony w standardzie HTML5.
- Przygotowanie responsywnego arkusza stylów CSS zgodnie z wytycznymi arkusza.

- 🎨 **Style CSS:** `styl.css`
