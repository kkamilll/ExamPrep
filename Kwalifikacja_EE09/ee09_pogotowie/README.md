# 📌 ee09_pogotowie (EE.09 (Programowanie i administrowanie stronami oraz bazami))

> **Temat zadania:** Dyspozytornia Pogotowia Ratunkowego  
> **Kwalifikacja:** EE.09 (Programowanie i administrowanie stronami oraz bazami)  
> **Technologie:** HTML5, CSS3, PHP, MySQL

---

## 📖 Opis zadania i co zostało zrobione

System rejestracji wyjazdów karetek, zespołów ratowniczych i zgłoszeń medycznych z kwerendami SQL i panelem PHP.

### Główne elementy rozwiązania:
- Opracowanie semantycznej struktury strony w standardzie HTML5.
- Przygotowanie responsywnego arkusza stylów CSS zgodnie z wytycznymi arkusza.
- Oprogramowanie skryptu backendowego w PHP (mysqli) do komunikacji z bazą danych MySQL.

---

## 📁 Pliki w tym zadaniu

- 🌐 **Pliki HTML:** `pogotowie.html`
- 🐘 **Skrypty PHP:** `zgloszenie.php`
- 📝 **Pliki tekstowe / Kwerendy:** `kwerendy.txt`
- 🎨 **Style CSS:** `styl5.css`

---

## 🚀 Instrukcja krok po kroku (co zrobić po pobraniu)

1. **Rozpakuj pobrane archiwum ZIP** do dowolnego folderu.

3. **Uruchomienie PHP:**
   - Skopiuj ten rozpakowany folder do katalogu `C:\xampp\htdocs\ee09_pogotowie`.
   - Uruchom moduł **Apache** w XAMPP.
   - Otwórz w przeglądarce adres: `http://localhost/ee09_pogotowie/zgloszenie.php`.
