# 📌 ee09_organizer (EE.09 (Programowanie i administrowanie stronami oraz bazami))

> **Temat zadania:** Miesięczny Organizer Zadań  
> **Kwalifikacja:** EE.09 (Programowanie i administrowanie stronami oraz bazami)  
> **Technologie:** HTML5, CSS3, PHP, MySQL

---

## 📖 Opis zadania i co zostało zrobione

Aplikacja kalendarza i organizera zadań z podziałem na dni miesiąca, skryptem PHP pobierającym wpisy i formularzem notatek.

### Główne elementy rozwiązania:
- Przygotowanie responsywnego arkusza stylów CSS zgodnie z wytycznymi arkusza.
- Oprogramowanie skryptu backendowego w PHP (mysqli) do komunikacji z bazą danych MySQL.

---

## 📁 Pliki w tym zadaniu

- 🐘 **Skrypty PHP:** `organizer.php`
- 🎨 **Style CSS:** `styl6.css`

---

## 🚀 Instrukcja krok po kroku (co zrobić po pobraniu)

1. **Rozpakuj pobrane archiwum ZIP** do dowolnego folderu.

3. **Uruchomienie PHP:**
   - Skopiuj ten rozpakowany folder do katalogu `C:\xampp\htdocs\ee09_organizer`.
   - Uruchom moduł **Apache** w XAMPP.
   - Otwórz w przeglądarce adres: `http://localhost/ee09_organizer/organizer.php`.
