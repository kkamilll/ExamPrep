# 📌 ee09_stacja_paliw (EE.09 (Programowanie i administrowanie stronami oraz bazami))

> **Temat zadania:** Stacja Paliw i Kalkulator Kosztów  
> **Kwalifikacja:** EE.09 (Programowanie i administrowanie stronami oraz bazami)  
> **Technologie:** HTML5, CSS3, JavaScript

---

## 📖 Opis zadania i co zostało zrobione

Aplikacja dla stacji paliw z interaktywnym kalkulatorem kosztów tankowania i obliczaniem zasięgu pojazdu w JavaScript.

### Główne elementy rozwiązania:
- Opracowanie semantycznej struktury strony w standardzie HTML5.
- Przygotowanie responsywnego arkusza stylów CSS zgodnie z wytycznymi arkusza.

---

## 📁 Pliki w tym zadaniu

- 🌐 **Pliki HTML:** `obliczenia.html`, `stacja.html`
- 🎨 **Style CSS:** `styl5.css`
