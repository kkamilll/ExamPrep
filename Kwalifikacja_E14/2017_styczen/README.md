# 📌 2017_styczen (E.14 (Tworzenie aplikacji internetowych i baz danych))

> **Temat zadania:** Komis Samochodowy i Baza Pojazdów  
> **Kwalifikacja:** E.14 (Tworzenie aplikacji internetowych i baz danych)  
> **Technologie:** HTML5, CSS3, PHP, MySQL

---

## 📖 Opis zadania i co zostało zrobione

Strona komisu samochodowego z wyszukiwarką aut, filtrowaniem po marce, modelu, roczniku i cenie z bazy MySQL.

### Główne elementy rozwiązania:
- Przygotowanie responsywnego arkusza stylów CSS zgodnie z wytycznymi arkusza.
- Oprogramowanie skryptu backendowego w PHP (mysqli) do komunikacji z bazą danych MySQL.

---

## 📁 Pliki w tym zadaniu

- 🐘 **Skrypty PHP:** `auta.php`
- 🎨 **Style CSS:** `style.css`

## 🚀 Instrukcja krok po kroku (co zrobić po pobraniu)

1. **Rozpakuj pobrane archiwum ZIP** do dowolnego folderu.

3. **Uruchomienie PHP:**
   - Skopiuj ten rozpakowany folder do katalogu `C:\xampp\htdocs\2017_styczen`.
   - Uruchom moduł **Apache** w XAMPP.
   - Otwórz w przeglądarce adres: `http://localhost/2017_styczen/auta.php`.
