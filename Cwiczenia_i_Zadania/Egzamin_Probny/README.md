# 📌 Egzamin_Probny (Ćwiczenia i Zadania (INF.03 / E.14 / EE.09))

> **Temat zadania:** Portal Notowań Giełdowych i Walut  
> **Kwalifikacja:** Ćwiczenia i Zadania (INF.03 / E.14 / EE.09)  
> **Technologie:** HTML5, CSS3, JavaScript, PHP

---

## 📖 Opis zadania i co zostało zrobione

Aplikacja finansowa prezentująca kursy walut, spółek giełdowych z kalkulatorem przewalutowania w JavaScript/PHP.

### Główne elementy rozwiązania:
- Przygotowanie responsywnego arkusza stylów CSS zgodnie z wytycznymi arkusza.
- Oprogramowanie skryptu backendowego w PHP (mysqli) do komunikacji z bazą danych MySQL.
- Implementacja logiki i obsługi zdarzeń po stronie klienta w JavaScript.

---

## 📁 Pliki w tym zadaniu

- 🐘 **Skrypty PHP:** `gielda.php`
- 📝 **Pliki tekstowe / Kwerendy:** `kwerendy.txt`
- 🎨 **Style CSS:** `style.css`
- ⚡ **Skrypty JS:** `skrypt.js`

## 🚀 Instrukcja krok po kroku (co zrobić po pobraniu)

   - Skopiuj ten rozpakowany folder do katalogu `C:\xampp\htdocs\Egzamin_Probny`.

   - Otwórz w przeglądarce adres: `http://localhost/Egzamin_Probny/gielda.php`.
